SiriusScope UI SVG DESIGN REFERENCE
===================================

Назначение файла
----------------
Этот файл описывает SVG-макет SiriusScope как дизайн-референс для разработки полноценного QML-интерфейса.
Описание предназначено для ИИ-агента или разработчика, который будет дорабатывать существующий QML UI.

Важно:
- SVG не нужно напрямую конвертировать в основной QML UI.
- SVG использовать как визуальную опору: цвета, пропорции, расположение, смысловые зоны, названия статусов, примерные размеры.
- Предлагаемые имена компонентов ниже являются примерами, а не обязательными требованиями.
- Динамические области должны быть живыми QML/C++ компонентами: спектр, waterfall, индикатор антенны, таблица событий, статусы.
- Если описание расходится с SVG, визуальный приоритет имеет SVG-файл.

Исходные параметры SVG
----------------------
Файл: siriusscope-ui-concept.svg
Заголовок SVG: Operator workspace concept
Описание SVG: Dark Qt desktop UI concept: spectrum, five band items, waterfall history, antenna indicator, result table, and status diagnostics.
Базовый размер: 1440 x 900 px
viewBox: 0 0 1440 900
Соотношение сторон: 16:10
Основная стилистика: тёмный операторский desktop UI, техническая панель управления, приборный интерфейс.

Координатная система
--------------------
Все координаты ниже указаны в пикселях относительно SVG 1440x900.
Для адаптивной QML-верстки использовать пропорции:

normalizedX = x / 1440
normalizedY = y / 900
normalizedW = width / 1440
normalizedH = height / 900

Рекомендуемый подход:
- На первом этапе можно использовать фиксированную базу 1440x900 и сверять с SVG.
- Затем перейти на QtQuick.Layouts, anchors и пропорции.
- Минимальная ширина для нормального вида интерфейса: около 1080 px.
- При меньшей ширине правая колонка может сжиматься сильнее или переходить в отдельную вкладку/панель.

Связь с существующим QML-проектом
---------------------------------
В текущей структуре SiriusScope уже есть QML-заготовка со следующими смысловыми частями:
- Main.qml
- MenuBarApp.qml
- SpectrumView.qml
- WaterfallView.qml
- AntennaIndicator.qml
- FooterDataView.qml
- BandModel.qml

SVG-макет следует использовать для визуального усиления этих компонентов:
- MenuBarApp.qml -> top-chrome + меню Режим/Файл/Правка/Справка.
- SpectrumView.qml -> spectrum-panel, spectrum-grid, spectrum-band-items, spectrum-axis.
- WaterfallView.qml -> waterfall-panel, waterfall-history, band overlays, direction controls.
- AntennaIndicator.qml -> antenna-panel, dial, bearing-markers, antenna-controls.
- FooterDataView.qml -> status-bar / diagnostics strip.
- Новый возможный компонент ResultTableView.qml -> result-table-panel.
- Новый возможный компонент TopToolbar.qml -> toolbar, mode-segment, toolbar-status, viewport-control.

Общая композиция экрана
-----------------------
Экран состоит из тёмного окна с верхней строкой меню, панелью управления, большой левой рабочей областью, правой колонкой управления антенной и таблицей событий, а также нижней статусной строкой.

Главная структура:
1. Оконная рамка / фон приложения.
2. Верхнее меню.
3. Верхняя панель инструментов.
4. Левая основная панель:
   - Верх: спектр.
   - Низ: waterfall / история обнаружений.
5. Правая верхняя панель:
   - Индикатор антенны, круговая шкала, цели, сектор луча.
   - Ручное управление наведением.
6. Правая нижняя панель:
   - Таблица последних событий/обнаружений.
7. Нижняя статусная строка:
   - Состояние программы, БКО, антенны, записи, диагностики.

Рекомендуемые layout-пропорции для Main.qml
-------------------------------------------
Если собирать через QtQuick.Layouts:

Главная вертикальная структура:
- TopChrome: фиксированная высота 30 px или системный MenuBar.
- TopToolbar: фиксированная высота 40 px.
- Content area: занимает основную высоту.
- FooterStatusBar: фиксированная высота 56 px.

В content area:
- Левая колонка: примерно 62.5% ширины экрана.
- Правая колонка: примерно 34.4% ширины экрана.
- Горизонтальный зазор между колонками: 12 px.
- Внешние отступы: 16 px слева/справа, 12 px между toolbar и content.

Левая колонка:
- SpectrumPlot: около 31% высоты левой панели.
- WaterfallView: около 56% высоты левой панели.
- Direction controls / легенда: около 5% высоты.
- Остальное: внутренние отступы и подписи осей.

Правая колонка:
- AntennaPanel: примерно 510 px из доступной высоты в SVG, около 56.7% экрана.
- ResultTablePanel: примерно 184 px, около 20.4% экрана.
- Между ними вертикальный зазор около 14 px.

Градиенты и эффекты
-------------------
chromeGrad:
- vertical gradient from #151C24 to #0A0E13.
- Использовать для общего фона окна или главной рабочей области.

panelGrad:
- vertical gradient from #16202A to #10161E.
- Использовать для основных панелей Spectrum, Antenna, ResultTable.

plotGrad:
- diagonal/large gradient from #101720 to #090D13.
- Использовать для фона графика спектра.

dialFace:
- gradient from #17222D to #0B1016.
- Использовать для фона круговой шкалы антенны.

panelShadow:
- SVG filter: feDropShadow dx=0, dy=10, stdDeviation=15, color #000000, opacity 0.28.
- В QML можно заменить на MultiEffect/DropShadow или временно не использовать.
- Тень не является функционально критичной. Важнее сохранить границы, радиусы, контраст.

QML implementation guidance
---------------------------
1. Сделать Theme.qml / DesignTokens.qml в первую очередь.
2. Создать повторно используемые компоненты Panel и StatusChip.
3. Не копировать SVG path в QML для всего интерфейса.
4. Спектр и waterfall должны оставаться data-driven.
5. Антенную шкалу лучше рисовать Repeater/Canvas/Shape, а не статичным SVG.
6. Таблицу реализовать как модель + delegate/TableView.
7. Использовать SVG как overlay в debug-режиме для сверки layout.
8. При переносе в существующий Main.qml сохранить текущую архитектуру RowLayout/ColumnLayout, но привести визуальные пропорции к SVG.
9. Все цвета band должны быть едиными между SpectrumView, WaterfallView, Antenna markers и таблицей.
10. Все числовые значения и телеметрию выводить моноширинным шрифтом.

Шаг 3. Стилизовать SpectrumView: панель, график, сетка, оси, bands.

Шаг 5. Переработать AntennaIndicator в визуальный вид SVG.
Шаг 6. Добавить ResultTablePanel, если его ещё нет в текущей QML-структуре.
Шаг 7. Превратить FooterDataView в FooterStatusBar.
Шаг 8. Подключить реальные данные C++ backend через properties/models.

Критерии визуального совпадения
-------------------------------
- Общий фон: почти чёрный, без светлых областей.
- Панели имеют тонкие сине-серые границы и лёгкий gradient.
- Верхний toolbar компактный, высота около 40 px.
- Левая рабочая область визуально доминирует.
- Спектр занимает верхнюю часть левой области, waterfall — нижнюю большую часть.
- Правая панель антенны должна быть приборной, с крупной круговой шкалой.
- Таблица событий компактная, не должна визуально конкурировать с антенной.
- Статусная строка снизу должна выглядеть как диагностическая полоса с chip-элементами.
- Цвета B1-B5 и статусы должны быть консистентными во всех местах интерфейса.
